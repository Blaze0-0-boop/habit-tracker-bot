# Habit Tracker Bot

Telegram-бот для формирования привычек. Он помогает отмечать ежедневные действия, следить за сериями и сохранять мотивацию с помощью наград и виртуального питомца.

## Возможности

- Добавление и удаление привычек (до 10 на пользователя).
- Ежедневные отметки и статистика за последние 7 дней.
- Подсчёт серий и бонусы за 3, 7, 14 и 30 дней.
- Опыт, достижения и питомец с пятью стадиями развития.
- Три стиля общения: мягкий друг, строгий тренер и шутник.
- Хранение данных в локальном JSON-файле.

## Стек

- Python
- python-telegram-bot
- python-dotenv
- JSON

## Запуск

Требуется Python 3.10 или новее.

1. Создайте Telegram-бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env` и задайте токен:

   ```env
   BOT_TOKEN=your_telegram_bot_token
   ```

4. Запустите бота:

   ```bash
   python bot.py
   ```

Файл `.env` и пользовательские данные `data.json` не входят в репозиторий. Бот сохраняет данные локально; для постоянной работы запустите его на сервере или хостинге.

## Демо

Демо доступно после запуска бота в Telegram. Публичная ссылка на экземпляр бота не включена в репозиторий.
